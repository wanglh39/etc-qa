## 关键设计：角色菜单映射

```
superadmin → 系统管理（账号/角色/操作日志/模拟登录）
ops        → 数据看板 + 运维管理（状态/监控/定时/告警）
admin      → 数据看板 + 业务管理（审核/审核历史）+ 内容管理（知识库/分类/配置）
service    → 客服工作台
dept       → 部门工单处理（售后/技术运维/财务）
```

## 关键设计：路由权限

```
meta: { roleAuth: 'admin,ops' }    → admin + ops + superadmin 可访问
meta: { roleAuth: 'superadmin' }   → 仅 superadmin
meta: { roleAuth: 'ops' }          → ops + superadmin
meta: { roleAuth: 'admin' }        → admin + superadmin
meta: { roleAuth: 'service' }      → service + superadmin
meta: { roleAuth: 'dept' }         → dept + superadmin
meta: { roleAuth: 'all' }          → 所有已登录角色
superadmin 可访问所有页面（路由守卫直接放行）
```
