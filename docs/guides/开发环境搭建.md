# 开发环境搭建指南

## 前置条件

| 工具 | 版本要求 | 下载地址 |
|------|---------|---------|
| Python | 3.10+ | https://www.anaconda.com/download |
| Docker Desktop | 最新版 | https://www.docker.com/products/docker-desktop/ |
| Git | 最新版 | https://git-scm.com/ |

## 方式一：一键搭建（推荐）

### Windows
```bash
git clone <仓库地址>
cd etc_qa
setup.bat
```

### Mac/Linux
```bash
git clone <仓库地址>
cd etc_qa
chmod +x setup.sh
./setup.sh
```

脚本会自动完成：安装依赖 → 下载模型 → 启动MySQL → 初始化数据库

## 方式二：手动搭建

### 1. 克隆项目 & 安装依赖
```bash
git clone <仓库地址>
cd etc_qa
pip install -r requirements.txt
```

### 2. 配置环境变量
```bash
cp .env.template .env
# 编辑 .env，填入你的 DEEPSEEK_API_KEY
```

DeepSeek API Key 获取：https://platform.deepseek.com 注册 → 充值 → 创建API Key
SiliconFlow API Keys 获取：https://siliconflow.cn 注册 → 创建多个 API Key（逗号分隔，负载均衡）

### 3. 下载 ASR 模型（约2.1GB）
```bash
pip install modelscope
python scripts/setup/download_models.py --models asr
```

> **注意**：Embedding（bge-large-zh-v1.5）和 Reranker（bge-reranker-v2-m3）已改用 SiliconFlow API 调用，无需下载本地模型文件。仅需下载 ASR 模型。

| 模型 | 用途 | 大小 |
|------|------|------|
| Fun-ASR-Nano-2512 | 语音识别 | ~2.1GB |

### 4. 启动MySQL
```bash
docker compose -f docker-compose.dev.yml up -d mysql
```

等待MySQL就绪（约15秒），验证：
```bash
docker compose -f docker-compose.dev.yml exec mysql mysqladmin ping -h localhost
```

### 5. 初始化数据库
```bash
set ETC_QA_ENV=dev  # Windows
# export ETC_QA_ENV=dev  # Linux/Mac

python scripts/data/init_db.py dev
```

## 启动服务

### Docker方式（推荐）
```bash
docker compose -f docker-compose.dev.yml up etc-qa
```

### 本地方式
```bash
python main.py
```

访问 API 文档：http://localhost:8000/docs

## 目录结构说明

```
etc_qa/
├── backend/
│   ├── models/          ← ASR模型文件（不入Docker镜像，volume挂载）
│   │   └── hub/
│   │       └── models/
│   │           └── FunAudioLLM/Fun-ASR-Nano-2512/
│   ├── data/            ← 数据文件（volume挂载）
│   │   ├── milvus/      ← Milvus Lite数据库
│   │   ├── processed/   ← CSV数据
│   │   └── asr_samples/ ← ASR测试音频

│   ├── .env.template    ← 密钥模板

│   ├── Dockerfile.dev   ← 开发环境镜像
│   └── scripts/setup/   ← 环境搭建脚本
└── frontend/            ← 前端（Vue3 + TypeScript）
    └── npm install && npm run dev
```

## 前端启动

```bash
cd frontend
npm install
npm run dev

# Vite 自动代理 /api → http://localhost:8000
```

## 常见问题

### Q: SiliconFlow API 报错/限流？
系统内置多 key 负载均衡，429/5xx 自动冷却切下一个 key。确保 `.env` 中 `SILICONFLOW_API_KEYS` 配置了多个逗号分隔的 key。

### Q: Docker启动报端口冲突？
修改 `docker-compose.dev.yml` 中的端口映射：
```yaml
mysql:
  ports:
    - "3307:3306"  # 改为其他端口
```

### Q: 不想用Docker跑MySQL？
可以直接连本地MySQL：
1. 本地安装MySQL 8.0
2. 修改 `config/database.yaml` 中 dev.host 为 localhost
3. 手动运行 `python scripts/data/init_db.py dev`

### Q: 队友没有GPU？
ASR模型默认配置 `device: cuda`，无GPU时修改 `config/asr.yaml`：
```yaml
asr:
  device: "cpu"
```
