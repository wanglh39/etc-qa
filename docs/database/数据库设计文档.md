# 数据库设计文档

MySQL 8.x + Milvus Lite。共 12 张 MySQL 表 + 1 个 Milvus 向量集合。

---

## 1. qa_pairs — 知识库问答对

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | INT AUTO_INCREMENT | 是 | 自增 | 主键 |
| question | VARCHAR(500) | 是 | - | 标准问题（向量化存入Milvus） |
| answer | TEXT | 否 | NULL | 对客话术 |
| category_l1 | VARCHAR(50) | 否 | NULL | 一级分类 |
| category_l2 | VARCHAR(50) | 否 | NULL | 二级分类 |
| internal_process | TEXT | 否 | NULL | 内部处理办法及流程 |
| feedback_dept | TEXT | 否 | NULL | 涉及反馈部门/工单模板 |
| image_url | VARCHAR(500) | 否 | NULL | 图片示例URL |
| status | VARCHAR(20) | 是 | 'active' | 状态：active/deprecated/archived |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间 |

**索引：** idx_status (status)、idx_category_l1 (category_l1)

---

## 2. categories — 分类树

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | INT AUTO_INCREMENT | 是 | 自增 | 主键 |
| label | VARCHAR(100) | 是 | - | 分类名称 |
| parent_id | INT | 否 | NULL | 父分类ID（NULL=一级分类） |
| description | VARCHAR(500) | 否 | NULL | 分类说明 |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间 |

**关系：** parent_id → categories.id（自引用，支持多级分类树）

## 13. qa_vectors — Milvus 向量集合

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT64 | 主键（原始向量=qa_id，HyDE向量=qa_id*1000+i） |
| qa_id | INT64 | 关联 qa_pairs.id |
| vector | FLOAT_VECTOR(1024) | 问题向量（SiliconFlow API: bge-large-zh-v1.5） |
| category_l1 | VARCHAR(50) | 一级分类（用于分类过滤） |
| is_hyde | BOOL | 是否为HyDE假设性向量 |

**索引：** HNSW (M=16, efConstruction=256, COSINE)

---

## 表关系

```
qa_pairs.id ←→ qa_vectors.qa_id       （一对多：1条知识 + N条HyDE向量）
qa_pairs.category_l1 → categories.label （分类关联）
qa_pairs.id ←→ audit_log.qa_id          （一对多：审核日志）
users.role → roles.role_key              （用户角色关联）
work_orders → (Agent预处理) → qa_pairs + qa_vectors  （工单入库流水线）
system_config ←→ config_center.py ←→ 所有业务代码    （配置中心）
prompt_templates ←→ PromptEngine ←→ LLM调用代码      （提示词管理）
alert_events.rule_id → 告警规则(代码内定义)           （告警关联）
scheduler_task_log.task_name → 调度任务(代码内定义)   （调度日志）
operation_log.operator → users.username               （操作日志）
```
