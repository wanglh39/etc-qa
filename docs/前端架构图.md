┌─────────────────────────────────────────────────────────┐
│                 路由守卫 (router.beforeEach)             │

## 认证数据流

```
┌──────────┐     POST /api/auth/login      ┌──────────┐
│ login.vue│ ──────────────────────────────→│ FastAPI  │
│          │ ←──── JWT token + role ────────│          │
└────┬─────┘                                └──────────┘
     │ sessionStorage.setItem('token', ...)
     │ sessionStorage.setItem('userRole', ...)
     ▼
┌──────────────────────────────────────────────────────┐
│ 每次API请求 (utils/request.ts)                        │
│                                                      │
│  Axios请求拦截器:                                     │
│    headers.Authorization = `Bearer ${token}`         │
│                                                      │
│  → 后端require_role校验 → 放行/拒绝(403)             │
└──────────────────────────────────────────────────────┘
     │
     │ 关闭浏览器
     ▼
  sessionStorage自动清除 → 重新打开必须重新登录
```

## 流式ASR架构

```
┌──────────────────────────────────────────────────┐
│ service/index.vue (客服工作台)                    │
│                                                  │
│  ┌──────────────────────────────────────────┐    │
│  │ useStreamingASR composable               │    │
│  │                                          │    │
│  │  麦克风采集 → 重采样16kHz → Int16 PCM    │    │
│  │       │                                  │    │
│  │       ▼                                  │    │
│  │  WebSocket (/ws/asr/stream)              │    │
│  │       │                                  │    │
│  │       ▼                                  │    │
│  │  消息处理:                               │    │
│  │    partial → partialText (实时显示)      │    │
│  │    final   → finalText   (完整识别)      │    │
│  │    query_result → queryResult (检索结果) │    │
│  └──────────────────────────────────────────┘    │
│                                                  │
│  录音按钮 → toggleRecording()                     │
│  实时识别区 → partialText / finalText             │
│  候选答案卡片 → queryResult.candidates            │
└──────────────────────────────────────────────────┘

Vite proxy:
  /ws → ws://localhost:8000 (ws: true)
  /api → http://localhost:8000
```
