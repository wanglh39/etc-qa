## 覆盖率

| 指标 | 后端 | 前端 | 门槛 |
|------|------|------|------|
| 语句 | ≥80% | 95.99% | 80% 硬门槛 |
| 分支 | ≥80% | 87.66% | 80% 硬门槛 |
| 函数 | ≥80% | 81.49% | 80% 硬门槛 |
| 行 | ≥80% | 95.99% | 80% 硬门槛 |

后端：`pytest --cov-fail-under=80`（pytest.ini 配置）
前端：`vitest.config.ts` 中 `coverage.thresholds` 配置

## CI Pipeline (9个job)

| Job | 阶段 | 命令 | 依赖 |
|-----|------|------|------|
| Backend · Lint | 代码风格 | ruff check + format | - |
| Backend · Unit Tests | 单元测试 | pytest --cov-fail-under=80 | Lint |
| Backend · Integration | 集成测试 | pytest -m integration (MySQL容器) | Unit |
| Backend · Benchmark | 性能基准 | pytest-benchmark | Unit |
| Backend · Security | 安全扫描 | bandit + safety | - |
| Frontend · Lint & Format | 代码风格 | eslint + prettier | - |
| Frontend · Type Check | 类型检查 | vue-tsc --noEmit | Lint |
| Frontend · Unit Tests | 单元+契约 | vitest --coverage (thresholds 80%) | TypeCheck |
| Frontend · E2E Tests | 端到端 | playwright test | Unit |

## 契约测试

| 校验项 | 说明 |
|--------|------|
| 端点存在性 | 前端所有 API 调用在后端 OpenAPI schema 中存在 |
| 无重复调用 | 前端 API 调用无重复 |
| 端点数量 | 后端 schema 端点数量在合理范围(40-60) |

文件：`frontend/tests/contract/api-contract.test.ts`
Schema：`frontend/tests/contract/openapi.json`（41个端点）
导出脚本：`backend/scripts/export_openapi.py`（从 FastAPI 自动生成）

## 运行命令速查

```bash
# 后端单元测试
cd backend && python -m pytest tests/ -q --ignore=tests/integration

# 后端集成测试（需要MySQL）
cd backend && python -m pytest tests/integration/ -m integration -q

# 后端性能测试
cd backend && python -m pytest tests/benchmark/ --benchmark-only -q -o addopts=""

# 后端压测（需要后端运行）
cd backend && locust -f scripts/locustfile.py --host=http://localhost:8000

# 前端单元测试
cd frontend && npm run test:run

# 前端覆盖率
cd frontend && npm run test:coverage

# 前端E2E测试
cd frontend && npm run e2e

# 前端代码检查
cd frontend && npm run lint && npm run format:check
```
