# 部署指南

## 一、开发环境部署

### 1.1 后端

```bash
cd backend
conda create -n etc_qa python=3.10 -y && conda activate etc_qa
pip install -r requirements.txt
cp .env.example .env  # 填入 DEEPSEEK_API_KEY
python scripts/data/init_db.py dev
python main.py
```

### 1.2 前端

```bash
cd frontend
npm install
npm run dev
```

### 1.3 Docker 开发环境

```bash
docker compose -f docker-compose.dev.yml up -d
```

## 二、生产环境部署

### 2.1 Docker Compose 部署

```bash
# 构建并启动
docker compose up -d --build

# 查看状态
docker compose ps

# 查看日志
docker compose logs -f etc-qa
```

### 2.2 环境变量

生产环境 `.env` 配置：

```env
DEEPSEEK_API_KEY=your_api_key
ETC_QA_ENV=prod
MYSQL_HOST=mysql
MYSQL_PORT=3306
MYSQL_USER=etc_qa
MYSQL_PASSWORD=your_password
```

### 2.3 数据库初始化

```bash
# 首次部署
python scripts/data/init_db.py prod
python scripts/data/init_config.py prod

# 权限迁移（如有新角色/权限）
python scripts/data/migrate_permissions.py
```

## 四、模型部署

### 4.1 SiliconFlow API 配置

Embedding（bge-large-zh-v1.5）和 Reranker（bge-reranker-v2-m3）通过 SiliconFlow API 调用，无需下载本地模型。

在 `.env` 中配置：
```bash
# 多个 key 逗号分隔，系统自动负载均衡（最长空闲优先，429/5xx 自动冷却切换）
SILICONFLOW_API_KEYS=sk-key1,sk-key2,sk-key3,sk-key4
```

### 4.2 配置阿里云NLS API Key

ASR已改用阿里云NLS实时语音识别API，无需下载本地模型。在 `.env` 中配置：

```bash
ALICLOUD_ASR_APP_KEY=你的AppKey
ALICLOUD_ASR_ACCESS_KEY_ID=你的AccessKeyID
ALICLOUD_ASR_ACCESS_KEY_SECRET=你的AccessKeySecret
ALICLOUD_ASR_HOTWORDS_ID=你的热词表ID
ASR_STREAMING_MODE=alicloud
```

## 五、监控部署

### 5.1 告警 Webhook（可选）

配置 `config/alert.yaml`：

```yaml
alert:
  webhook:
    enabled: true
    url: "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx"
```

### 5.2 日志

- 应用日志：`backend/logs/etc_qa.log`（10MB 轮转，5 个备份）
- 访问日志：stdout（Docker logs）

## 六、升级流程

1. 拉取最新代码：`git pull origin main`
2. 更新依赖：`pip install -r requirements.txt && npm install`
3. 数据库迁移：`python scripts/data/migrate_permissions.py`（如有）
4. 重启服务：`docker compose restart` 或 `python main.py`
5. 验证健康：`curl http://localhost:8000/api/health` → `{"status":"ok"}`

---

## 七、回滚流程

1. 回退代码：`git reset --hard <previous_version>`
2. 重启服务：`docker compose restart`
3. 验证健康：`curl http://localhost:8000/api/health`
4. 如数据库有 schema 变更，需手动回退 DDL
