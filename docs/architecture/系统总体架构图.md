## 数据流

```
                    ┌─────────┐
                    │ 客服来电 │
                    └────┬────┘
                         │
         ┌───────────────▼───────────────┐
         │     WebSocket 流式ASR链路      │
          │  阿里云NLS识别→纠错→6层过滤│
         └───────────────┬───────────────┘
                         │
         ┌───────────────▼───────────────┐
         │       RAG 检索链路             │
         │  Agent标准化(2步)              │
         │  → Embedding编码               │
         │  → 双路并行召回(Milvus+BM25)   │
         │  → RRF合并 → Reranker精排      │
         │  → 阈值判定 → 返回候选答案      │
         └───────────────┬───────────────┘
                         │
                    ┌────▼────┐
                    │ 客服审核 │
                    └────┬────┘
                         │
              ┌──────────┴──────────┐
              │                     │
        ┌─────▼─────┐        ┌──────▼──────┐
        │ 命中→回电  │        │ 未命中→工单  │
        └───────────┘        └──────┬──────┘
                                     │
                     ┌───────────────▼───────────────┐
                     │     入库链路 (定时调度)         │
                     │  拉取工单→Agent预处理(3步)      │
                     │  → 去重→写入待审核(deprecated)  │
                     │  → 人工审核→入库(active)       │
                     │  → 双写MySQL+Milvus            │
                     └───────────────────────────────┘
```
