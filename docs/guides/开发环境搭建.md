# 开发环境搭建指南

## 前置条件

| 工具 | 版本要求 | 下载地址 |
|------|---------|---------|
| uv | 最新版 | https://docs.astral.sh/uv/getting-started/installation/ |
| Docker Desktop | 最新版 | https://www.docker.com/products/docker-desktop/ |
| Git | 最新版 | https://git-scm.com/ |

## 方式一：一键搭建（推荐）

### Windows
```bash
git clone <仓库地址>
cd etc_qa
setup.bat
```

### Mac/Linux
```bash
git clone <仓库地址>
cd etc_qa
chmod +x setup.sh
./setup.sh
```

脚本会自动完成：安装依赖 → 启动MySQL → 初始化数据库

## 方式二：手动搭建

### 1. 克隆项目 & 安装依赖
```bash
git clone <仓库地址>
cd etc_qa/backend

# 创建虚拟环境（uv自动下载Python 3.10）
uv venv etc_qa --python 3.10

# 安装依赖（用清华镜像加速）
uv pip install pycryptodome -p etc_qa/Scripts/python.exe
uv pip install aliyunsdkcore --no-deps -p etc_qa/Scripts/python.exe
uv pip install -r requirements.txt -p etc_qa/Scripts/python.exe --index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 配置环境变量
```bash
cp .env.example .env
# 编辑 .env，填入你的 DEEPSEEK_API_KEY
```

DeepSeek API Key 获取：https://platform.deepseek.com 注册 → 充值 → 创建API Key
SiliconFlow API Keys 获取：https://siliconflow.cn 注册 → 创建多个 API Key（逗号分隔，负载均衡）

### 3. 配置阿里云NLS API Key

ASR已改用阿里云NLS实时语音识别API，无需下载本地模型。

在阿里云NLS控制台（https://nls-portal.console.aliyun.com）创建应用和热词表，然后在 `.env` 中配置：

```bash
ALICLOUD_ASR_APP_KEY=你的AppKey
ALICLOUD_ASR_ACCESS_KEY_ID=你的AccessKeyID
ALICLOUD_ASR_ACCESS_KEY_SECRET=你的AccessKeySecret
ALICLOUD_ASR_HOTWORDS_ID=你的热词表ID
ASR_STREAMING_MODE=alicloud
```

> **注意**：Embedding/Reranker走SiliconFlow API，ASR走阿里云NLS API，均无需下载本地模型文件。

### 4. 启动MySQL
```bash
docker compose -f docker-compose.dev.yml up -d mysql
```

等待MySQL就绪（约15秒），验证：
```bash
docker compose -f docker-compose.dev.yml exec mysql mysqladmin ping -h localhost
```

### 5. 初始化数据库
```bash
set ETC_QA_ENV=dev  # Windows
# export ETC_QA_ENV=dev  # Linux/Mac

python scripts/data/init_db.py dev
```

## 启动服务

### Docker方式（推荐）
```bash
docker compose -f docker-compose.dev.yml up etc-qa
```

### 本地方式
```bash
python main.py
```

访问 API 文档：http://localhost:8000/docs

## 目录结构说明

```
etc_qa/
├── backend/

│   ├── data/            ← 数据文件（volume挂载）
│   │   ├── milvus/      ← Milvus Lite数据库
│   │   ├── processed/   ← CSV数据
│   │   └── asr_samples/ ← ASR测试音频
│   ├── .env             ← 密钥（不入镜像，不提交Git）
│   ├── .env.example    ← 密钥模板
│   ├── docker-compose.dev.yml  ← 开发环境编排
│   ├── Dockerfile.dev   ← 开发环境镜像
│   └── scripts/setup/   ← 环境搭建脚本
└── frontend/            ← 前端（Vue3 + TypeScript）
    └── npm install && npm run dev
```

## 前端启动

```bash
cd frontend
npm install
npm run dev
# 默认监听 http://localhost:5173
# Vite 自动代理 /api → http://localhost:8000
```

## 常见问题

### Q: SiliconFlow API 报错/限流？
系统内置多 key 负载均衡，429/5xx 自动冷却切下一个 key。确保 `.env` 中 `SILICONFLOW_API_KEYS` 配置了多个逗号分隔的 key。

### Q: Docker启动报端口冲突？
修改 `docker-compose.dev.yml` 中的端口映射：
```yaml
mysql:
  ports:
    - "3307:3306"  # 改为其他端口
```

### Q: 不想用Docker跑MySQL？
可以直接连本地MySQL：
1. 本地安装MySQL 8.0
2. 修改 `config/database.yaml` 中 dev.host 为 localhost
3. 手动运行 `python scripts/data/init_db.py dev`

### Q: 队友没有GPU？
ASR已改用阿里云NLS API，无需GPU。Embedding/Reranker走SiliconFlow API，也无需GPU。整个系统无需GPU即可运行。
