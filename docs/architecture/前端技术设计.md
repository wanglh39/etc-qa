## 三、角色权限体系

### 3.1 角色矩阵

系统采用RBAC（基于角色的访问控制）模型，共5个角色，按企业级四层分离设计：

| 角色 | 定位 | 菜单页面 | 默认账号 |
|------|------|---------|---------|
| **superadmin** | 系统管理层 | 账号管理 / 角色管理 / 操作日志 / 模拟登录 | superadmin |
| **ops** | 运维层 | 数据看板 / 系统状态总览 / 性能监控 / 定时任务 / 异常告警 | ops |
| **admin** | 业务管理层 | 数据看板 / 待审核 / 审核历史 / 知识库 / 分类管理 / 配置管理 | admin |
| **service** | 操作层 | 客服工作台 | service |
| **dept** | 操作层 | 售后/技术运维/财务 工单处理 | dept |

> 初始密码由 `.env` 的 `ETC_QA_*_PASSWORD` 配置（开发环境默认 `dev123456`，生产环境必须显式配置）。

**设计原则**：
- 业务管理员(admin)不管运维，运维工程师(ops)不管业务
- 超级管理员(superadmin)只管"谁能干什么"（账号/角色/日志/模拟登录），不直接管业务也不直接管运维
- superadmin可访问所有页面（管理/审计需要），可通过"模拟登录"以其他角色身份查看系统
- 其余角色只能访问权限范围内页面

### 3.2 登录跳转

每个角色登录后跳转到自己的首页（最常用功能页）：

```
superadmin → /workbench/admin/account      （账号管理）
ops        → /workbench/admin/status       （系统状态总览）
admin      → /workbench/admin/dashboard    （数据看板）
service    → /service                      （客服工作台）
dept       → /dept/handle/{userDept}       （部门工单处理）
```

### 3.3 路由守卫

全局前置守卫（`router.beforeEach`）执行流程：

```
1. 去登录页 → 重置验证标志，放行
2. 无token → 跳登录页
3. JWT过期检查 → 解码exp字段，过期则清理跳登录
4. 首次导航 → 调后端/api/auth/verify验证token有效性
5. 角色信息缺失 → 清理跳登录
6. 角色权限校验：
   - roleAuth未设置或'all' → 放行
   - superadmin → 放行所有页面
   - 其他角色 → 检查roleAuth逗号分隔列表是否包含当前角色
   - 不通过 → 提示"无权访问"，跳回该角色默认首页
```

**权限配置示例**：
```ts
meta: { roleAuth: 'admin,ops' }    // admin和ops可访问，superadmin也可
meta: { roleAuth: 'superadmin' }   // 仅superadmin
meta: { roleAuth: 'ops' }          // ops和superadmin
meta: { roleAuth: 'all' }          // 所有已登录角色
```

### 5.2 StatisticCard.vue — 增强型统计卡片

```vue
<StatisticCard
  title="待审核知识"
  :value="12"
  desc="需及时处理"
  :icon="User"
  icon-color="#E6A23C"
  :growth="15"                                    <!-- 环比增长15% -->
  :alert="true"                                   <!-- 状态色标：左侧红色边框 -->
  :progress="{ current: 8, total: 12 }"            <!-- 进度条：8/12=67% -->
  :sparkline="[3, 5, 2, 8, 6, 10, 12]"            <!-- 迷你折线趋势 -->
  to="/workbench/admin/auditList"                  <!-- 点击跳转 -->
/>
```

| 属性 | 类型 | 说明 |
|------|------|------|
| `value` | string\|number | 数值，number类型触发count-up动画（800ms缓动） |
| `growth` | number | 环比增长率，正数红色↑，负数绿色↓ |
| `to` | string | 点击跳转路径，hover时上浮+阴影+"点击查看→"提示 |
| `progress` | {current, total} | 底部进度条，宽度=current/total*100% |
| `alert` | boolean | 告警色标，左侧3px红色边框+进度条变红 |
| `sparkline` | number[] | 底部SVG迷你折线，展示趋势走势 |
| `iconColor` | string | 图标颜色，同时作为进度条和折线颜色 |

- count-up动画：数值从0缓动到目标值（cubic-out easing，800ms）
- hover动画：卡片上浮4px + 阴影增强 + "点击查看→"淡入
- 告警色标：`alert=true`时左侧红色边框，适合"待审核积压"等异常提示
- 企业级看板标配的"可操作+可感知"卡片设计

### 5.3 useStreamingASR.ts — 流式语音识别

```ts
const { recording, partialText, finalText, queryResult, toggleRecording } = useStreamingASR()
```

- 封装WebSocket连接 + 麦克风采集 + 重采样16kHz + Int16 PCM转换
- 对外暴露响应式状态：recording（录音中）、partialText（部分识别）、finalText（完整识别）、queryResult（检索结果）
- 自动重连 + 安全上下文检测 + 麦克风权限错误提示

## 八、安全设计

### 8.1 认证流程

```
登录 → 后端返回JWT token → 存入sessionStorage
每次请求 → Axios拦截器自动加Authorization: Bearer {token}
首次导航 → 调/api/auth/verify验证token有效性
路由守卫 → 解码JWT检查exp过期
退出/过期 → sessionStorage.clear() + 跳登录页
```

### 8.2 sessionStorage vs localStorage

系统使用`sessionStorage`存储认证信息（非`localStorage`）：

- **关浏览器自动清除**：每次打开浏览器必须重新登录，避免token长期有效
- **标签页隔离**：不同标签页session独立，避免多账号串扰
- **安全上下文**：XSS无法跨标签页读取sessionStorage

### 8.3 权限双重校验

- **前端路由守卫**：roleAuth校验，无权限页面不可访问
- **后端接口校验**：`require_role("admin", "superadmin", "ops")`，即使前端被绕过，后端也拒绝
- **前后端一致**：每个API端点的角色权限与前端路由roleAuth对应

## 十、流式ASR接入

### 10.1 架构

```
前端麦克风 → 重采样16kHz → Int16 PCM → WebSocket → 后端转发阿里云NLS WebSocket → on_partial/on_final回调
     ↑                                                              ↓
     └── partialText/finalText/queryResult ← JSON消息 ←──────────────┘
```

### 10.2 useStreamingASR composable

```ts
const {
  recording,      // 是否录音中
  partialText,    // 部分识别结果（实时更新）
  finalText,      // 完整识别结果
  queryResult,    // RAG检索结果
  toggleRecording // 切换录音
} = useStreamingASR()
```

- 麦克风采集：`navigator.mediaDevices.getUserMedia({ audio: true })`
- 重采样：AudioContext采样率转16kHz
- PCM转换：Float32 → Int16
- WebSocket消息：ready/state_change/partial/final/query_result/filtered/corrected/error
- 安全检测：`navigator.isSecureContext`检测，非HTTPS提示
- 权限处理：麦克风拒绝时分类错误提示
