# 数据库设计文档

## 1. qa_pairs — 知识库问答对

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | INT AUTO_INCREMENT | 是 | 自增 | 主键 |
| question | VARCHAR(500) | 是 | - | 标准问题（向量化存入Milvus） |
| answer | TEXT | 否 | NULL | 对客话术 |
| category_l1 | VARCHAR(50) | 否 | NULL | 一级分类（售前业务/售后业务/充电业务/衍生业务/运证通/其它） |
| category_l2 | VARCHAR(50) | 否 | NULL | 二级分类（动态，从数据中加载） |
| internal_process | TEXT | 否 | NULL | 内部处理办法及流程（给客服看的） |
| feedback_dept | TEXT | 否 | NULL | 涉及反馈部门/微信群/工单模板 |
| image_url | VARCHAR(500) | 否 | NULL | 图片示例URL |
| status | VARCHAR(20) | 是 | 'active' | 知识状态：active/deprecated/archived |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间（自动维护） |

**索引建议：**
- `idx_status` ON (status) — 检索时过滤 active 记录
- `idx_category_l1` ON (category_l1) — 分类查询

## 2. qa_vectors — Milvus 向量集合

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT64 | 主键（原始向量=qa_id，HyDE向量=qa_id*1000+i） |
| qa_id | INT64 | 关联 qa_pairs.id |
| vector | FLOAT_VECTOR(1024) | 问题向量（bge-large-zh-v1.5） |
| category_l1 | VARCHAR(50) | 一级分类（用于分类过滤） |
| is_hyde | BOOL | 是否为HyDE假设性向量 |

**索引：** HNSW (M=16, efConstruction=256, COSINE)

**说明：**
- 原始向量：is_hyde=false，id=qa_id
- HyDE向量：is_hyde=true，id=qa_id*1000+i（i从1开始）
- 检索时默认过滤 is_hyde=false，只搜原始向量
- 启用HyDE时不过滤，同时搜原始+HyDE向量

## 3. work_orders — 工单记录

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | INT AUTO_INCREMENT | 是 | 自增 | 主键 |
| external_id | VARCHAR(100) | 否 | NULL | 外部工单系统ID |
| raw_data | TEXT | 否 | NULL | 原始数据JSON |
| status | VARCHAR(20) | 是 | 'submitted' | 状态流转 |
| created_at | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间 |

**status 流转：**

```
submitted → answered → processed → deduped → imported/rejected
```

| 状态 | 说明 |
|------|------|
| submitted | 已提交到外部工单系统 |
| answered | 外部系统已处理，拉取到本地 |
| processed | Agent预处理完成 |
| deduped | 去重完成，待入库 |
| imported | 已入库知识库 |
| rejected | 去重判定为重复，不入库 |

## 4. system_config — 业务配置

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| config_key | VARCHAR(100) | 是 | - | 主键，配置项名称 |
| config_value | JSON | 是 | - | 配置值（JSON格式） |
| description | VARCHAR(500) | 否 | NULL | 配置说明 |
| updated_at | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间 |

**预置配置项：**

| config_key | JSON类型 | 说明 |
|------------|---------|------|
| forbidden_new_kws | string[] | 幻觉检测关键词 |
| must_preserve_kws | string[] | 必须保留关键词 |
| brand_keywords | string[] | 品牌名列表 |
| subject_keywords | string[] | 业务主体关键词 |
| question_words | string[] | 疑问词列表 |
| preserve_question_words | string[] | 必须保留疑问词 |
| filler_patterns | string[] | 口语填充词正则 |
| core_patterns | object[] | 同义替换规则 |
| clean_rules | string[] | 业务清洗正则 |
| qa_statuses | string[] | 合法知识状态枚举 |

**读取优先级：** DB > config.yaml > 代码默认值

---

## 5. prompt_templates — 提示词模板

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| prompt_key | VARCHAR(100) | 是 | - | 主键，模板名称 |
| template_text | TEXT | 是 | - | 模板文本（支持{variable}占位符） |
| version | INT | 是 | 1 | 版本号（自动递增） |
| is_active | TINYINT | 是 | 1 | 是否为当前活跃版本 |
| description | VARCHAR(500) | 否 | NULL | 模板说明 |
| updated_at | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间 |

**版本管理：** 更新模板时，旧版本 is_active=0，新版本 version+1, is_active=1

---

## 表关系

```
qa_pairs.id ←→ qa_vectors.qa_id  （一对多：1条知识 + N条HyDE向量）
work_orders → (经过Agent预处理) → qa_pairs + qa_vectors
system_config ←→ config_center.py ←→ 所有业务代码
prompt_templates ←→ config_center.py ←→ LLM调用代码
```
