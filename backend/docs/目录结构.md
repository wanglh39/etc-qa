## 关键设计：应用生命周期管理（企业级）

```
uvicorn reload=true
┌─────────────────────────────────────────┐
│ 主进程 (Reloader)                       │
│ - 只监控文件变化                        │
│ - 不加载模型 (lifespan不触发)           │
│ - 不初始化Milvus                        │
└──────────┬──────────────────────────────┘
           │ fork
┌──────────▼──────────────────────────────┐
│ 子进程 (Server)                         │
│ - lifespan startup:                     │
│   ├─ 加载Embedding/Reranker模型(GPU)    │
│   ├─ 初始化MySQL/Milvus连接             │
│   ├─ FileLock进程锁保护Milvus初始化     │
│   ├─ RAG预热                            │
│   └─ ASR预热（如启用）                  │
│ - 接受请求 → 推理                       │
│ - lifespan shutdown:                    │
│   └─ 关闭Milvus连接，释放资源           │
└─────────────────────────────────────────┘
```

- **lifespan管理**：create_service()在FastAPI lifespan中执行，只有子进程触发，主进程不加载模型
- **FileLock进程锁**：FileLock串行化Milvus初始化，防止reload重启时争抢SQLite锁
- **workers=1**：GPU显存有限（8GB），只加载一份模型
